# モデルだけで答えさせた場合と、MCP のツールを使わせた場合（測った記録）

2026-11-27 に、同じ 3 つの問いを、モデルだけ（ツールなし）と、setsuzei の MCP サーバーをつないだ状態で答えさせました。

**限界を先に**: 問いは 3 つ、モデルは 1 種類（Claude Sonnet 5.5）、モデルだけは各 3 回、ツールありは各 1 回です。ほかのモデル・ほかの問い・回数を増やした場合にどうなるかは測っていません。「モデルは税額を計算できない」という一般的な主張の根拠にはなりません。

## 方法

- 実行: Claude Code（`claude -p`、`--model sonnet`）。
  - モデルだけ: `--tools ""` と空の MCP 設定で、ツールを使えない状態にし、「ツールは使わず、あなたの知識だけで計算してください」と添えた。
  - ツールあり: setsuzei の MCP サーバーだけをつなぎ（`--strict-mcp-config`）、「setsuzei のツールを使って答えてください」と添えた。
- どの問いも「最後の行に『答え: N 円』の形で数字を 1 つだけ」と指定し、その数字を読み取った。
- 正しい値: 同じ条件で CLI（`setsuzei --json`）を実行した値。CLI の値は、公表されている計算例や条文から手計算した値とテストで突き合わせている。

## 問いと結果

| | 問い（令和8年分） | 正しい値 | モデルだけ（3 回） | ツールあり（1 回） |
|---|---|---|---|---|
| Q1 | 給与収入 500 万円・社会保険料 75 万円・独身の会社員の、ふるさと納税の上限（自己負担 2,000 円、1,000 円未満切り捨て） | 57,000 円 | 57,000 / **61,000** / **61,000** | 57,000 |
| Q2 | フリーランス、売上 800 万円・経費 150 万円・青色 65 万円・社会保険料 90 万円・独身の、所得税（復興特別所得税を含む）と令和9年度の住民税の合計 | 891,900 円 | 891,900 / 891,900 / 891,900 | 891,900 |
| Q3 | フリーランス、売上 480 万円・経費 75 万円・青色 65 万円・社会保険料 59 万円・独身の、ふるさと納税の上限 | 57,000 円 | **61,000** / **61,000** / **61,000** | 57,000 |

- モデルだけの 9 回のうち、正しかったのは 4 回でした。税額の合計（Q2）は 3 回とも正しく、ふるさと納税の上限（Q1・Q3）は 6 回のうち 5 回が 61,000 円でした。
- 61,000 円は、令和7年分までの計算での値です。令和8年分は、所得税の基礎控除の引上げで、この所得帯の上限が 57,000 円に下がります（[説明と根拠](https://ozko00.github.io/setsuzei/furusato-nozei-jogen-reiwa8/)）。モデルがなぜ 61,000 円と答えたかは調べていません。
- ツールありの 3 回は、3 回ともツールを呼び、返ってきた値をそのまま答えました。

## 再現するには

問いの全文と実行したコマンドは、この節のとおりです（`<...>` は自分の環境のパスに置き換える）。

```sh
# モデルだけ
claude -p "<問い> ツールは使わず、あなたの知識だけで計算してください。" --model sonnet \
  --mcp-config <空の設定.json> --strict-mcp-config --tools "" --output-format json

# ツールあり（設定.json は README の MCP の設定）
claude -p "<問い> setsuzei のツールを使って答えてください。" --model sonnet \
  --mcp-config <設定.json> --strict-mcp-config \
  --allowedTools "mcp__setsuzei__estimate_tax_savings,mcp__setsuzei__furusato_nozei_limit,mcp__setsuzei__compare_furusato_limit_with_2025,mcp__setsuzei__validate_tax_input,mcp__setsuzei__list_tax_sources" \
  --output-format json
```
